# Resultados y entorno computacional

Esta carpeta conserva información asociada a la reproducción final.

- `sessionInfo.txt`: versión de R, plataforma, paquetes adjuntos y paquetes cargados durante la ejecución validada.

Las figuras, archivos Excel y tablas CSV generados por los scripts se mantienen actualmente en la raíz del proyecto porque esa es la ubicación producida por la versión de código que fue auditada y reproducida. Se conservan como resultados de referencia para facilitar la comparación con ejecuciones posteriores.
